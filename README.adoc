= Advanced Ansible Network Automation Workshop
:toc: macro
:toc-title: Table of Contents
:icons: font

image:https://img.shields.io/badge/License-MIT-yellow.svg[License: MIT,link=LICENSE]

A hands-on workshop for automating multi-vendor **EVPN VXLAN spine-leaf fabrics** using **Red Hat Ansible Automation Platform**. Participants work through progressive modules covering dynamic inventory with NetBox, configuration management via Git, network compliance, automated deployment of base/underlay/overlay configurations, performance tuning, and configuration drift detection.

The lab environment runs Arista EOS and Cisco NX-OS virtual switches on link:https://containerlab.dev/[Containerlab^], managed through AAP workflows with NetBox as the source of truth and Gitea as the Git backend.

Designed for link:https://demo.redhat.com[Red Hat Demo Platform (RHDP)^] with the Showroom UI.

== Lab environment

* A **Containerlab host** with `ansible-navigator`, VS Code, and a pre-built execution environment
* **Six network devices**: Arista EOS (spine1, spine2, leaf1, leaf2) and Cisco NX-OS (leaf3, leaf4)
* **Ansible Automation Platform** for workflow-driven automation
* **NetBox** as the dynamic inventory source
* **Gitea** as the Git repository for network configurations

== Architecture

----
                    ┌─────────────────────────────┐
                    │       BGP EVPN Overlay       │
                    │    (eBGP, AS 65000 ↔ 65001)  │
                    └─────────────────────────────┘

              spine1 (EOS)                spine2 (EOS)
              AS 65000                    AS 65000
              ┌──────────┐                ┌──────────┐
              │  EVPN RR │                │  EVPN RR │
              └─┬──┬──┬──┘                └──┬──┬──┬─┘
                │  │  │  │                │  │  │  │
          ┌─────┘  │  │  └──────┐   ┌─────┘  │  │  └──────┐
          │        │  │         │   │         │  │         │
      ┌───┴────┐┌──┴──┴──┐┌────┴───┐┌────────┐
      │  leaf1 ││  leaf2  ││  leaf3 ││  leaf4  │
      │  (EOS) ││  (EOS)  ││ (NXOS) ││ (NXOS)  │
      │  VTEP  ││  VTEP   ││  VTEP  ││  VTEP   │
      └──┬─────┘└──┬──────┘└──┬─────┘└──┬──────┘
         │          │          │          │
      ┌──┴───┐  ┌──┴───┐  ┌──┴───┐  ┌──┴────┐
      │host1 │  │host2 │  │host3 │  │host4  │
      │VLAN50│  │VLAN50│  │VLAN40│  │VLAN60 │
      └──────┘  └──────┘  └──────┘  └───────┘
----

Both spines act as EVPN route reflectors. All four leafs are VTEPs sourcing VXLAN tunnels from Loopback0. Three data VLANs (40, 50, 60) are stretched across the fabric in VRF `gold` with symmetric IRB for inter-subnet routing.
